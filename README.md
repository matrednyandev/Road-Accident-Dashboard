# 🚗 Road Accident Dashboard

## 📊 Project Overview

This project presents an interactive Road Accident Dashboard designed to analyze road accident data and identify important patterns related to casualties, accident severity, vehicle types, weather conditions, road surfaces and locations.

The dashboard helps users understand accident trends and provides useful insights for road safety analysis.

## 🛠️ Tools & Technologies

- Power BI
- Excel
- Data Cleaning
- Data Visualization
- DAX

## 📌 Key KPIs

- Total Accidents
- Total Casualties
- Fatal Casualties
- Serious Casualties
- Slight Casualties

## 📈 Dashboard Features

- Year-wise accident analysis
- Current Year vs Previous Year comparison
- Fatal casualties by vehicle type
- Fatal casualties by weather condition
- Casualties by road surface
- Casualties by location
- Road surface-wise casualty analysis
- Interactive accident severity filter
- Monthly accident trends
- Geographic accident analysis

## 🔍 Key Insights

- The majority of casualties are categorized as slight casualties.
- Single carriageways contribute the highest number of fatal casualties.
- Fine weather conditions account for the largest share of fatal casualties.
- Dry road surfaces have the highest proportion of casualties.
- Cars contribute significantly to fatal casualties compared with other vehicle types.

## 🎯 Objective

The main objective of this project is to analyze road accident data and provide meaningful insights that can help understand accident patterns and support road safety decision-making.
